# Code of Conduct

We want a welcoming, rigorous, and safe community.

Positive behavior includes curiosity, respect, constructive feedback, acknowledging uncertainty, giving credit, and making space for people with different backgrounds and experience levels.

Unacceptable behavior includes harassment, discrimination, threats, doxxing, personal attacks, sexualized attention without consent, and sustained disruption of good-faith collaboration.

This applies to project spaces, issue trackers, pull requests, discussions, community events, and public interactions when someone is representing the project.

Report concerns privately to project maintainers through a verified contact route. Include links and context where safe. Maintainers should respond promptly, protect confidentiality, avoid retaliation, and use proportionate measures. If a maintainer is involved, contact another trusted steward or GitHub reporting channels.

This document is a starting point and may be improved through community review.
